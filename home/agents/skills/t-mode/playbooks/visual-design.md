# Visual Design

For visual/UX/product direction and design artifacts without implementation.

- Assign one designer to Opus 5.5 high unless the user specified otherwise.
  Do not add a separate reviewer or a design process by default.
- Brief the audience, target surface, references, constraints, requested form
  and count, and output location (default `.agents/share/design/<work-id>/`).
  Respect actual permissions for shared artifacts and all Figma access rules.
- The designer creates the artifacts and checks them against the request,
  reporting rationale and unresolved points. Intake inspects the actual outputs,
  their identity, requested form/count, and available evidence. A missing artifact
  or unmet requirement is not complete; do not present subjective claims as
  independently verified quality. Do not require user approval for routine work.
- A revision follows the common continuity rules, preserving prior artifacts
  and feedback. Subsequent implementation uses the dev playbook with the design
  artifact as input; no automatic user checkpoint is inserted.
